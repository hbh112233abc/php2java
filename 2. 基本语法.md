## 2. 基本语法

Java 的基本语法可以从这几个核心板块来梳理，掌握它们就能读懂大部分 Java 代码。

### 2.1 程序结构

一个 Java 程序由**类**组成，每个类可包含**方法**，程序入口是 `main` 方法。

```java
public class Hello {
    public static void main(String[] args) {
        System.out.println("Hello, World");
    }
}
```

- 文件名必须与 `public` 类名一致（`Hello.java`）
- `main` 方法固定签名：`public static void main(String[] args)`
- Java 严格区分大小写

### 2.2 标识符与关键字

**标识符**（类名、变量名、方法名）规则：
- 由字母、数字、`_`、`$` 组成，不能以数字开头
- 不能是关键字（如 `class`、`int`、`if`）
- 不能包含空格

**命名约定**：

| 类型      | 规范         | 示例                 |
| --------- | ------------ | -------------------- |
| 类名      | 大驼峰       | `StudentInfo`        |
| 方法/变量 | 小驼峰       | `getAge`、`userName` |
| 常量      | 全大写下划线 | `MAX_SIZE`           |
| 包名      | 全小写       | `com.example.demo`   |

### 2.3 变量与常量

```java
int age = 18;              // 变量
final double PI = 3.14;    // 常量，赋值后不可改
```

变量必须先声明、后使用，且要初始化才能读取。

### 2.4 运算符

```java
// 算术
+  -  *  /  %        // 5 % 2 == 1

// 关系（返回 boolean）
==  !=  >  <  >=  <=

// 逻辑
&&  ||  !            // 短路运算

// 赋值
=  +=  -=  *=  /=  %=

// 自增自减
i++  ++i  i--  --i

// 三元
int max = a > b ? a : b;

// 位运算
&  |  ^  ~  <<  >>  >>>
```

注意 `&&` 和 `||` 有**短路特性**：`false && x` 不会计算 x。

### 2.5 流程控制

#### 2.5.1 条件语句

```java
if (score >= 90) {
    System.out.println("优秀");
} else if (score >= 60) {
    System.out.println("及格");
} else {
    System.out.println("不及格");
}

switch (day) {
    case 1:
        System.out.println("周一");
        break;
    default:
        System.out.println("其他");
}
```

Java 14+ 支持箭头式 switch：

```java
switch (day) {
    case 1, 2, 3 -> System.out.println("上半周");
    default -> System.out.println("下半周");
}
```

#### 2.5.2 循环语句

```java
// for
for (int i = 0; i < 5; i++) {
    System.out.println(i);
}

// 增强 for（遍历数组/集合）
for (int n : arr) {
    System.out.println(n);
}

// while
while (condition) { ... }

// do-while（至少执行一次）
do { ... } while (condition);
```

#### 2.5.3 跳转语句

```java
break;        // 跳出当前循环
continue;     // 跳过本次，进入下一次
return;       // 结束方法
```

### 2.6 数组

```java
int[] arr = new int[5];              // 默认全 0
int[] nums = {1, 2, 3};              // 静态初始化
int[][] matrix = {{1,2}, {3,4}};     // 二维数组

arr.length                            // 长度属性
```

### 2.7 方法

```java
修饰符 返回值类型 方法名(参数列表) {
    // 方法体
    return 结果;
}

public static int add(int a, int b) {
    return a + b;
}
```

- `void` 表示无返回值
- 支持**重载**：同名方法，参数列表不同
- 参数是**值传递**：基本类型传值，引用类型传地址副本

### 2.8 面向对象基础语法

```java
public class Person {
    // 字段
    private String name;
    private int age;

    // 构造方法
    public Person(String name, int age) {
        this.name = name;
        this.age = age;
    }

    // 方法
    public void sayHello() {
        System.out.println("我是 " + name);
    }

    // getter/setter
    public String getName() { return name; }
}
```

**四大修饰符访问权限**：

| 修饰符    | 本类 | 同包 | 子类 | 任意 |
| --------- | ---- | ---- | ---- | ---- |
| private   | ✓    | ✗    | ✗    | ✗    |
| 默认      | ✓    | ✓    | ✗    | ✗    |
| protected | ✓    | ✓    | ✓    | ✗    |
| public    | ✓    | ✓    | ✓    | ✓    |

**继承与多态**：

```java
class Student extends Person {
    @Override
    public void sayHello() {   // 重写
        System.out.println("我是学生");
    }
}

Person p = new Student("Tom", 18);  // 向上转型
p.sayHello();                        // 动态绑定，调用子类方法
```

### 2.9 异常处理

```java
try {
    int r = 10 / 0;
} catch (ArithmeticException e) {
    System.out.println("除零错误：" + e.getMessage());
} finally {
    System.out.println("总会执行");
}
```

### 2.10 常见易错点

- **字符串比较**：用 `equals()` 而不是 `==`，`==` 比较的是引用地址
- **`switch` 忘记 `break`** 会穿透到下一个 case
- **`for` 循环中修改集合** 会抛 `ConcurrentModificationException`
- **`finally` 中 return** 会覆盖 try 中的返回值
- **`static` 方法** 中不能直接访问非静态成员

### 2.11 PHP转JAVA示例

有 PHP 基础再学 Java，很多概念是相通的（面向对象、变量、循环），但**语法习惯和类型系统**差别较大。下面按常见场景做对照。

#### 2.11.1 整体差异对照

| 维度       | PHP                          | Java                                     |
| ---------- | ---------------------------- | ---------------------------------------- |
| 语言类型   | 弱类型、动态                 | 强类型、静态（编译期检查）               |
| 变量声明   | `$name = "Tom";`             | `String name = "Tom";`                   |
| 运行方式   | 解释执行（脚本）             | 编译成 `.class` 再在 JVM 上运行          |
| 结束符     | 每条语句 `;`，可省略最后一条 | 每条语句必须 `;`                         |
| 字符串拼接 | `.`（点号）                  | `+`（加号）                              |
| 数组       | 数组 / 关联数组一套搞定      | 数组（定长）+ `List`/`Map`（变长）分开   |
| 函数       | 顶层函数 `function foo()`    | 必须定义在类中，是「方法」               |
| 空值       | `null` / `isset()`           | `null` / `Optional`，基本类型不可为 null |
| 判等       | `==` 值比较、`===` 严格比较  | `==` 比引用、`equals()` 比值             |

#### 2.11.2 变量与输出

```php
<?php
$name = "Tom";
$age = 18;
echo "我是 $name，今年 $age 岁";
```

```java
public class Demo {
    public static void main(String[] args) {
        String name = "Tom";
        int age = 18;
        System.out.println("我是 " + name + "，今年 " + age + " 岁");
    }
}
```

要点：
- Java 变量必须**先声明类型**，类型一旦确定不能改
- 输出用 `System.out.println()`（自带换行）或 `System.out.print()`（不换行）
- 字符串插值 Java 用 `+` 拼接，或 `String.format("我是 %s，今年 %d 岁", name, age)`

#### 2.11.3 数组与集合

PHP 的数组「一个打十个」，Java 则分得很细。

```php
<?php
// 索引数组
$fruits = ["apple", "banana"];

// 关联数组
$user = ["name" => "Tom", "age" => 18];
echo $user["name"];
```

```java
import java.util.*;

public class Demo {
    public static void main(String[] args) {
        // 定长数组
        String[] fruits = {"apple", "banana"};

        // 变长列表，等价于 PHP 索引数组
        List<String> list = new ArrayList<>();
        list.add("apple");
        list.add("banana");

        // 键值对，等价于 PHP 关联数组
        Map<String, Object> user = new HashMap<>();
        user.put("name", "Tom");
        user.put("age", 18);
        System.out.println(user.get("name"));
    }
}
```

| PHP 写法                | Java 写法                            |
| ----------------------- | ------------------------------------ |
| `count($arr)`           | `list.size()`（数组用 `arr.length`） |
| `$arr[] = $v;`          | `list.add(v);`                       |
| `in_array($v, $arr)`    | `list.contains(v)`                   |
| `array_key_exists(...)` | `map.containsKey(...)`               |
| `isset($a["k"])`        | `map.get("k") != null`               |
| `implode(",", $arr)`    | `String.join(",", list)`             |
| `sort($arr)`            | `Collections.sort(list);`            |

#### 2.11.4 遍历

```php
<?php
foreach ($fruits as $fruit) {
    echo $fruit;
}

foreach ($user as $key => $value) {
    echo "$key = $value";
}
```

```java
// 增强 for，遍历列表/数组
for (String fruit : fruits) {
    System.out.println(fruit);
}

// 遍历 Map
for (Map.Entry<String, Object> entry : user.entrySet()) {
    System.out.println(entry.getKey() + " = " + entry.getValue());
}
```

#### 2.11.5 函数与方法

PHP 的顶层函数在 Java 中必须放进类里，并且要表明**返回值类型**。

```php
<?php
function add(int $a, int $b): int {
    return $a + $b;
}
echo add(1, 2);
```

```java
public class Demo {
    // 放在类中，修饰符 + 返回类型 + 方法名
    public static int add(int a, int b) {
        return a + b;
    }

    public static void main(String[] args) {
        System.out.println(add(1, 2));
    }
}
```

要点：
- Java 方法签名格式：`修饰符 返回类型 方法名(参数类型 参数名)`
- 无返回值用 `void`，且不能有 `return 值`
- 参数是**值传递**：传基本类型改不了原值，传对象改的是同一个对象的内部状态

#### 2.11.6 类与对象

PHP 和 Java 的思路一致，但 Java 的字段类型、`new` 语法更严格。

```php
<?php
class Person {
    private string $name;

    public function __construct(string $name) {
        $this->name = $name;
    }

    public function sayHello(): void {
        echo "我是 " . $this->name;
    }
}

$p = new Person("Tom");
$p->sayHello();
```

```java
public class Person {
    private String name;

    // 构造方法：方法名与类名相同，无返回值
    public Person(String name) {
        this.name = name;
    }

    public void sayHello() {
        System.out.println("我是 " + this.name);
    }

    public static void main(String[] args) {
        Person p = new Person("Tom");
        p.sayHello();     // 调用方法用「点」，不是「->」
    }
}
```

| PHP                     | Java                       |
| ----------------------- | -------------------------- |
| `$this->name`           | `this.name`                |
| `$obj->method()`        | `obj.method()`             |
| `__construct()`         | 与类名同名的方法           |
| `public function foo()` | `public void foo()`        |
| `extends` 继承          | `extends` 继承（写法一致） |
| `instanceof` 判断类型   | `instanceof` 判断类型      |

#### 2.11.7 字符串处理

```php
<?php
$s = "Hello World";
echo strlen($s);            // 11
echo strtoupper($s);        // HELLO WORLD
echo str_contains($s, "World"); // true
echo str_replace("World", "Java", $s);
echo substr($s, 0, 5);      // Hello
```

```java
String s = "Hello World";
System.out.println(s.length());               // 11
System.out.println(s.toUpperCase());          // HELLO WORLD
System.out.println(s.contains("World"));      // true
System.out.println(s.replace("World", "Java"));
System.out.println(s.substring(0, 5));        // Hello（左闭右开）
System.out.println(s.equals("Hello World"));  // 判断内容用 equals
```

#### 2.11.8 常见功能对照表

| 功能         | PHP                 | Java                                         |
| ------------ | ------------------- | -------------------------------------------- |
| 空字符串判断 | `empty($s)`         | `s == null \|\| s.isEmpty()`                 |
| 类型转换     | `(int) $s`          | `Integer.parseInt(s)`                        |
| 绝对值       | `abs($n)`           | `Math.abs(n)`                                |
| 四舍五入     | `round($n)`         | `Math.round(n)`                              |
| 最大值       | `max($a, $b)`       | `Math.max(a, b)`                             |
| 随机整数     | `rand(1, 10)`       | `new Random().nextInt(1, 11)`                |
| 时间戳       | `time()`            | `System.currentTimeMillis() / 1000`          |
| 格式化日期   | `date("Y-m-d")`     | `LocalDate.now()` / `DateTimeFormatter`      |
| JSON 编码    | `json_encode($arr)` | `new ObjectMapper().writeValueAsString(obj)` |
| 打印调试     | `var_dump($v)`      | `System.out.println(v)`                      |

#### 2.11.9 思维转变小结

从 PHP 转向 Java，重点记住这几点：

- **一切都要有类型**：变量、参数、返回值都要明确声明类型
- **一切都在类里**：没有顶层函数，方法是类的成员
- **数组 ≠ 数组**：定长用 `[]`，变长用 `List`，键值用 `Map`
- **判等用 `equals`**：`==` 比较的是引用地址，字符串/对象内容比较一律用 `equals()`
- **先编译后运行**：写错类型编译期就会报错，这是 Java 的优势也是门槛
