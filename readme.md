# JAVA 快速入门学习手册

> 面向 PHP 开发者的 Java 转型指南：从语法基础到 SpringBoot 企业级开发，一站式入门。

## 简介

本手册记录了一名 PHPer 转 Java 开发的完整学习路径，内容覆盖 **Java 基础语法**、**SpringBoot**、
**MyBatis-Plus**、**Redis**、**SaToken 鉴权**、**日志与接口文档** 等实战主题。

每一章都遵循「先配置、再代码、后验证」的顺序，所有示例均可直接运行，帮助 PHP 开发者用最短时间
建立起 Java 工程化开发的完整认知。

## 目标读者

- 有 PHP / 其他后端语言基础，准备转 Java 的开发者
- 熟悉 `Laravel`、`ThinkPHP` 等框架，想快速上手 `SpringBoot` 的工程师
- 需要一个可复用的 SpringBoot 项目脚手架的开发者

## 学习路线建议

```text
0. 环境配置
   └─> 1. 数据类型 ─> 2. 基本语法 ─> 3. 脚本测试      （补齐语言基础）
         └─> 4. SpringBoot 初始化 ─> 5. SprintMVC      （跑通 Web 层）
               └─> 6. MyBatis-Plus ─> 7. CURD 接口     （打通数据层）
                     └─> 8. Redis ─> 9. SaToken        （中间件与认证）
                           └─> 10. SwaggerUI ─> 11. logback （工程配套）
                                 └─> 12. SzAdmin       （综合实战）
```

- **只想快速上手业务开发**：可跳过第 1~3 章，直接从 [4. SpringBoot 初始化](./4.%20SprintBoot初始化.md) 开始。
- **想理解 Java 与 PHP 的差异**：重点阅读 `1.6`、`2.11` 两节的对照示例。

## 使用说明

1. 按 [0. 环境配置](./0.%20环境配置.md) 完成 JDK21、Maven3.9、VsCode 的安装与配置。
2. 按章节顺序阅读，每章都包含可复制的配置与代码。
3. 动手部分配合 `examples/demo` 工程：`mvn spring-boot:run` 启动后可即时验证效果。
4. 遇到 PHP 与 Java 的写法差异，优先查阅对应章节末尾的「PHP 转 JAVA 示例」。
