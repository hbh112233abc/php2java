## 10. 集成SwaggerUI

### 10.1 引入依赖

```xml
<!-- SwaggerUI（必须用 -ui 版本，才包含 UI 前端页面；-api 仅提供 /v3/api-docs 文档接口） -->
<dependency>
    <groupId>org.springdoc</groupId>
    <artifactId>springdoc-openapi-starter-webmvc-ui</artifactId>
    <version>3.1.1</version>
</dependency>
```

### 10.2 配置(可选)

> 若想在生产环境禁用，只需将 springdoc.swagger-ui.enabled 和 springdoc.api-docs.enabled 设为 false

```yml
springdoc:
  swagger-ui:
    path: /swagger-ui.html      # 自定义 UI 路径
    enabled: true               # 是否启用 Swagger UI
  api-docs:
    path: /v3/api-docs          # 自定义 API 文档路径
    enabled: true               # 是否启用文档生成
```

### 10.3 SaToken放行

`demo/src/main/java/com/example/demo/config/SaTokenConfig.java`

```java
// 放行SwaggerUI
.addExclude("/swagger-ui/**")
.addExclude("/v3/api-docs/**")
```

### 10.4 配置类(可选)

```java
package com.example.demo.config;

import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;

import io.swagger.v3.oas.models.OpenAPI;
import io.swagger.v3.oas.models.info.Info;
import io.swagger.v3.oas.models.info.Contact;

/**
 * Swagger/OpenAPI 文档元信息配置（标题、版本、描述等）
 */
@Configuration
public class OpenApiConfig {

    @Bean
    public OpenAPI apiInfo() {
        return new OpenAPI().info(
                new Info()
                        .title("Demo 接口文档")
                        .description("Spring Boot + MyBatis-Plus + Sa-Token 示例项目接口")
                        .version("v1.0.0")
                        .contact(new Contact().name("admin").email("admin@example.com"))
        );
    }
}
```

### 10.5 访问

- [Swagger-UI](http://localhost:8080/api/swagger-ui.html)
- [api-docs](http://localhost:8080/api/v3/api-docs)
